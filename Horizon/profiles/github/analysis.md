# Evaluation goal

Evaluate the importance and interest of GitHub repositories and open-source projects for developers tracking the open-source ecosystem.

# Scoring rubric

- **9-10: Landmark.** Major new projects or releases with broad ecosystem impact (e.g., a new foundational framework, a breakthrough tool).
- **7-8: High value.** Popular, fast-growing repositories, or significant releases of widely-used tools.
- **5-6: Interesting.** Noteworthy projects with a narrower audience or incremental improvements.
- **3-4: Low priority.** Minor updates or small utility repositories.
- **0-2: Noise.** Trivial, promotional, or abandoned content.

# Evaluation guidance

Judge by star growth, ecosystem relevance, and developer utility. Prefer concrete facts (repository name, stars, primary language, use case). A repository gaining thousands of stars overnight is high value; a minor utility with few stars is noise.
